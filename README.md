연속혈당측정(CGM) 의료기기 기업에서 환자용 혈당 모니터링 서비스와 사내 실험 데이터 플랫폼을 개발하고 있으며, React, Spring·Flask, PostgreSQL, AWS로 운영까지 함께 맡고 있습니다.

특히 **운영 중인 의료 서비스를 중단 없이 개선하는 일**을 많이 해왔습니다.
온프레미스 서비스를 AWS로 옮기고, blue/green 무중단 배포를 만들고, 테스트 없던 레거시에 테스트와 자동 롤백을 붙였습니다.<br>
이전 회사(2022.03 ~ 2024.04)에서 Spring 기반 포털·LMS·시설물 관리 시스템을 개발·운영한 경험을 바탕으로, 지금은 의료 서비스의 백엔드와 인프라를 맡고 있습니다.<br>
사이드 프로젝트로는 5인 팀에서 가챠샵 지도 서비스 **GOTCHA**를 만들어 App Store에 출시했습니다.

<br>

### 최근에 한 일

- 온프레미스 의료 서비스 **AWS 무손실 이전 2건** (전 테이블 일치 검증, 데이터 유실 0건)
- **blue/green 무중단 배포** 3개 서비스에 적용 (배포 중 서비스 중단 0건)
- 데이터 플랫폼 목록 조회 **20초 → 0.6초**, 리포트 쿼리 **29회 → 3회**
- 테스트 없던 레거시에 CI 테스트 게이트 도입 (**0개 → 211개**), 실패 시 자동 롤백
